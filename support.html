开始使用

第一次打开，从哪里开始？

先打开一个网页，再认识侧边栏和工具栏。iPhone 地址栏在底部，从屏幕左边缘向右滑打开侧边栏；iPad 和宽屏的工具栏在顶部。点侧边栏搜索按钮，或按 ⌘⇧P，可查找标签、固定网站、历史记录和浏览器命令。

找不到某个功能按钮怎么办？

先打开工具栏的「更多」。媒体视图、网页工具、页面笔记、AI 助手等入口可在这里找到。选择「自定工具栏」整理显示项目和顺序。工具是否可用取决于当前页面、系统版本和 Pro 权益。

支持哪些设备与系统？

支持 iOS / iPadOS 18 及以上的 iPhone 与 iPad；网页扩展需要 18.4 或更高版本。窄窗口自动使用紧凑布局，双网页工作台适合宽屏。iPad 搭配妙控键盘、触控板和 Apple Pencil 使用更舒适；触控操作同样可用。

空间、标签与无痕

怎样固定标签、排序和创建文件夹？

拖动标签可调整顺序。长按标签或点右键选择固定，也可以拖到侧边栏上方的快捷区域。点底部「＋」新建文件夹，再把标签拖入文件夹。普通标签与固定网站是不同入口：关闭网页不等于删除固定网站。

同一个网站怎样登录不同账号？

从侧边栏底部「＋」新建 Profile，并启用独立登录。不同空间使用各自的网站数据；原有空间是否独立以空间设置为准。网站登录状态不包含在备份中，换设备或恢复后可能需要重新登录。

怎样进入和结束无痕空间？

点侧边栏底部「＋ → 进入无痕空间」最直接。也可以在侧边栏横向滑动到普通空间最左侧之外；边界有防误触阻力，需要明确完成滑动。无痕顶部的「结束」会关闭无痕会话；无痕不等于对网站或网络匿名，也不会自动清除已下载到文件夹的文件。

关闭或清除标签后能恢复吗？

普通标签可用 ⌘⇧T 恢复，或使用界面提供的撤销操作。「清除」关闭当前空间打开的网页，保留固定网站入口。无痕会话结束后不应依赖历史记录或恢复标签找回内容。

扩展与用户脚本

怎样安装猫抓、SingleFile 等扩展？

打开「设置 → 网页扩展」，优先使用应用内的商店安装入口。6.3 适配了猫抓与 SingleFile，但不保证所有桌面扩展可完整运行。查看权限后启用扩展，再从扩展菜单使用或固定到工具栏；它们需要网页扩展可用的系统和相应 Pro 权益。

商店安装能用，本地导入为什么不行？

本地支持 .crx、.xpi、.zip，但安装方式可能改变插件标识。依赖 Lumo 专用适配的扩展可能因此无法接通书签、历史或跳转接口。柠檬起始页请优先从 Lumo 内的商店搜索安装；不要仅凭同名或旧版本号判断本地包也能使用。反馈时附插件版本与安装来源。

柠檬起始页安装后怎样设为新标签页？

安装并启用后，在「设置 → 默认浏览设置」的「新标签页页面」选择该扩展，再新建一个普通标签页查看。现有标签不会被自动替换，无痕标签使用 Lumo 自带页面。更换插件前先导出插件自己的数据。

篡改猴同步和用户脚本怎么用？

使用 Lumo 内置的用户脚本管理，导入脚本或篡改猴 ZIP / JSON 备份；需要同步时在脚本设置中配置自己的 WebDAV。导入前查看兼容性、同名脚本处理和启用状态。这里适配的是脚本与备份格式，不代表篡改猴扩展本体可以在 WebKit 中完整运行。

更新前已安装 Dark Reader，需要删除吗？

6.3 已内置网页深色适配。建议先停用 Dark Reader 扩展，避免同一网页被两套配色同时处理；确认内置效果合适后，再自行决定是否移除扩展。不要为了排查颜色问题先清除网站数据。

外观与网页显示

网页深色模式怎样跟随系统？

在「设置 → 外观」选择浅色、深色或跟随系统。网页会使用相应的深色适配；若某个站点显示异常，可到站点设置单独选择外观，再刷新查看。网站自身主题与扩展也会影响最终颜色。

水印和工具栏怎样自定义？

在外观相关设置中编辑水印文字，支持颜文字与 Emoji，并可预览、关闭或恢复默认。工具栏从「更多 → 自定工具栏」调整；常用工具可固定，顺序可以拖动整理。

网页打不开、显示不全或按钮无反应？

先保存未提交的表单，再刷新。依次检查该网站的桌面／移动版、浏览器身份、缩放与站点设置；临时停用影响该站点的扩展、用户脚本或拦截规则，每次只改一项。也可试「兼容模式」，再用同设备同网络的 Safari 对比。反馈请说明网址、页面模式与具体操作。

为什么后台网页有时会重新加载？

系统内存紧张时可能回收网页进程；Lumo 保留标签信息并在选中后恢复加载。页面中的未保存表单或临时状态不一定能完整恢复。编辑重要资料时请及时保存，避免同时开启大量重型网页。

下载、保存与监控

删除 App 后，下载文件会保留吗？

默认 Lumo 文件夹属于 App，删除 App 时会一起删除。想保留今后的下载，请在「设置 → 默认浏览设置」更改下载文件夹，选择 Lumo 容器之外的位置，例如 iCloud 云盘。原有文件不会自动迁移，请先用「文件」App 移动；第三方云盘的保留情况也取决于该服务。

下载文件夹不可用或下载失败怎么办？

先在「文件」App 确认目标文件夹可访问、云盘已登录且空间足够，再回到设置重新选择文件夹。Lumo 不会在目录失效时悄悄改存别处。文件下载不等于录制视频流，受保护媒体和部分流媒体无法直接保存。

怎样保存网页、批注或提取内容？

从页面操作或「更多」使用 PDF、整页长截图、页面笔记、批注、阅读列表与专业工具箱。宽屏可并排对照网页。工具箱提取结果取决于网页是否实际加载内容；若报告为空，先滚动加载目标区域，再重新扫描。部分工具属于 Pro。

网页监控能每分钟在后台检查吗？

6.3 新增 1、5、10 分钟间隔。Lumo 打开时按设定检查；后台运行时间由 iOS / iPadOS 决定，可能间隔数小时，不能保证准点。监控使用创建时所属空间的登录数据；需要登录的网站请在该空间确认会话仍有效。

备份、同步与恢复

同步和备份有什么区别？

iCloud 同步让受支持的空间、固定网站、书签与设置在设备间保持一致；备份是某个时间点的副本。日常同步不能替代备份。可在「设置 → 备份与同步」检查状态、启用自动备份或手动导出。

自动备份在哪里？包含哪些内容？

自动备份保存在「文件 → iCloud 云盘 → Lumo → Backups」，保留最近 3 份。自动备份不包含密码与扩展安装包；备份也不包含网站登录状态、已下载文件或缓存网页。手动导出可选择类别；要包含密码，需设置加密口令。

换设备或重装后怎样恢复？

先确认使用同一个 iCloud 账户并等待同步，再检查 Lumo 提供的备份恢复提示，或从备份页面导入文件。按类别恢复会替换设备上对应的数据，请先保留当前重要内容，并按提示彻底关闭、重开 Lumo 完成。网站与扩展可能需要重新登录；加密口令丢失后无法找回。

AI、Pro 与权限

怎样开始使用 AI？网页内容发给谁？

在「设置 → 助手」配置服务地址、模型与自己的 API Key，再打开 AI 助手提问。页面读取遵循你的授权与站点限制；相关内容直接发给你选择的服务，不经过 Lumo 服务器。API 服务费用和 Lumo Pro 是两回事，购买 Pro 不包含第三方 API 额度。

购买 Pro 后没有解锁，或换设备后丢失？

网页扩展、用户脚本、AI 助手、媒体视图和网页监控等功能需要 Pro。确认 App Store 使用购买时的 Apple 账号，在 Lumo Pro 页面点「恢复购买」。月度、年度订阅可在系统「Apple 账号 → 订阅」管理，也有永久购买方案。价格以 App 内当地商店为准；账单与退款由 Apple 处理。

本地网络权限会影响插件访问内网吗？

访问路由器、NAS 或其他内网服务时，系统可能要求本地网络权限。可在系统设置中检查 Lumo 的授权。但这不是所有插件通用的通行证：插件还受网站访问权限、WebKit 支持范围、HTTPS／证书和服务本身限制。不要为了排查而关闭系统安全保护。

通行密钥或网站登录失败怎么办？

检查设备的密码管理器、钥匙串与身份验证设置；确认登录发生在正确的 Profile 中。部分登录服务限制浏览器环境，可按站点切换网页模式或身份，并与 Safari 对比。在 Safari 登录不代表会话自动转移到 Lumo。
